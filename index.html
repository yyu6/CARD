Study protocol

Judge the discussion, not the formatting.

  1. The original post is identical for Thread A and Thread B.
  2. Both sides show the same number of comments.
  3. Reply indentation preserves the source thread structure.
  4. Author names, timestamps, scores, and model labels are hidden.
  5. Select “Cannot distinguish” when neither side appears more real.
